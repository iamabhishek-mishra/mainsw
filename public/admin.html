API Documentation

The store uses a JSON API backed by SQLite (data.db). All product management from this panel writes to that database.

MethodEndpointDescription
POST/api/admin/loginAdmin login {username, password} → token (Bearer)
POST/api/admin/logoutRevoke admin token
GET/api/categoriesList categories
GET/api/productsList products (?category, ?search, ?bestseller=1)
GET/api/products/:idGet one product
POST/api/productsCreate product (header X-Admin: <ADMIN_KEY>)
PUT/api/products/:idUpdate product
DELETE/api/products/:idDelete product
POST/api/auth/registerCreate account {name, email, password}
POST/api/auth/loginLogin {email, password} → token
POST/api/auth/logoutInvalidate session
GET/api/auth/meCurrent user (Bearer token)
POST/api/ordersPlace order {payment_method: cod|upi}
GET/api/ordersList orders (header X-Admin)
GET/api/orders/:idPublic order details
PUT/api/orders/:id/statusUpdate order status (admin)
GET/api/myordersLogged-in user's orders
GET/api/usersAll users + spend (admin)
POST/api/payments/initStart PhonePe payment for an order
GET/api/payments/callbackPhonePe redirect/verify callback
GET/api/payments/simulateLocal test payment (no merchant creds)
